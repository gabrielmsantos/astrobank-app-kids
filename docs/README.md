## 📞 Quick Reference

### Important Files
- `lib/main.dart` - App entry point
- `lib/config/app_config.dart` - API configuration
- `lib/screens/home_screen.dart` - Main dashboard
- `web/manifest.json` - PWA configuration

### Key Classes
- `Customer` - Customer data
- `Transaction` - Transaction data
- `CreditCard` - Card details
- `Invoice` - Invoice data
- `InvoiceItem` - Invoice line items

### Main Services
- `AuthService` - Authentication
- `CustomerService` - Customer profile
- `TransactionService` - Transaction pagination
- `CardService` - Cards and invoices
